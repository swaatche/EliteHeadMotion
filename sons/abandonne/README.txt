Installation abandonnée / Abandoned settlement

FR : sons joués uniquement hors du vaisseau (SRV ou à pied) sur une installation abandonnée.
  - boucles/   : sons qui bouclent proprement (vent, structure...), joués ensemble ;
  - ponctuels/ : sons courts joués au hasard (grincement, alarme lointaine...) ;
  - bases.txt : installations supplémentaires à reconnaître, un nom par ligne.
Dossiers vides : vent synthétisé.

EN: sounds played only outside the ship (SRV or on foot) at an abandoned settlement.
  - boucles/   : sounds that loop cleanly (wind, structure...), played together;
  - ponctuels/ : short sounds played at random (creak, distant alarm...);
  - bases.txt : extra settlements to recognise, one name per line.
Empty folders: synthesised wind.
