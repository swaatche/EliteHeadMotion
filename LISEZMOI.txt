============================================================
  ELITE HEAD MOTION v0.1 - par swaatche
  Mouvements de tête et secousses du pilote
============================================================

Ce mod amplifie les mouvements de tête dans le cockpit :

  - le regard suit les virages ;
  - la tête est poussée en accélérant, en freinant et en strafant ;
  - le cockpit subit des secousses sous les dégâts, aux sauts FSD, au boost...

Il fonctionne AVEC ou SANS head tracker (Tobii, TrackIR,
webcam...). Le choix se fait dans la page de réglages.

Le jeu n'est pas modifié : le mod se fait passer pour un
TrackIR (head tracking).


------------------------------------------------------------
1. PRÉREQUIS
------------------------------------------------------------

  - Windows 10 ou 11
  - Elite Dangerous
  - OpenTrack, installé (gratuit) :
    https://github.com/opentrack/opentrack/releases
    Le mod utilise un de ses fichiers : il doit être installé
    dans tous les cas, même sans head tracker.
  - Facultatif : un head tracker reconnu par OpenTrack
    (Tobii Eye Tracker, TrackIR, webcam...).


------------------------------------------------------------
2. INSTALLATION
------------------------------------------------------------

  1. Copiez le dossier du mod où vous voulez (par exemple dans
     Documents). Gardez l'exe dans son dossier : les réglages
     y sont enregistrés.
  2. Rien à régler dans Elite : le jeu reconnaît le mod tout
     seul au démarrage (comme un TrackIR).


------------------------------------------------------------
3. CHOISIR TON MODE D'UTILISATION
------------------------------------------------------------

En haut de la page de réglages, la liste déroulante
"Mode d'utilisation" propose :

  - Sans head tracker (vue fixe)
  - Tobii Eye Tracker (via OpenTrack)
  - TrackIR (via OpenTrack)
  - Autre tracker : webcam, smartphone... (via OpenTrack)

Cliquez sur le bouton "?" à côté de la liste : il affiche la
mise en place pas à pas pour le mode choisi (OpenTrack,
logiciels Tobii ou TrackIR). Le changement de mode s'applique
tout de suite, sans relancer le mod.

En résumé :
  - Sans head tracker : OpenTrack installé mais PAS lancé.
  - Avec un tracker : dans OpenTrack, entrée = votre tracker,
    sortie = "UDP over network", adresse 127.0.0.1,
    port 5555. Puis cliquez sur Start.
    Ne pas choisir la sortie "freetrack".
  - Un seul head tracking à la fois : fermez Tobii Game Hub
    (c'est lui qui pilote la vue dans Elite) et le logiciel
    TrackIR de NaturalPoint doit être désactivé.
  - Avec un Tobii : Tobii Experience doit rester OUVERT (il
    fait fonctionner le Tobii), seul Tobii Game Hub est fermé.


------------------------------------------------------------
4. UTILISATION
------------------------------------------------------------

  1. Avec un tracker seulement : lance OpenTrack et clique
     sur Start.
  2. Lance EliteHeadMotion.exe. Le terminal lance le mode, 
     puis la page de réglages s'ouvre dans le navigateur.
     Si elle ne s'ouvre pas : http://127.0.0.1:8765
  3. Lancer Elite Dangerous APRÈS le mod.
  4. Sur la page, le bandeau "Effets actifs dans le jeu" doit
     être vert.

  Pour quitter : cliquer sur "Quitter", cela ferme le serveur.


------------------------------------------------------------
5. PREMIER RÉGLAGE : LES COMMANDES
------------------------------------------------------------

Sur la page de réglages, section "Axes HOTAS", cliquez sur
"Détecter" pour chaque ligne, puis bougez l'axe ou appuiez sur
la touche :

  - Tangage, Lacet, Roulis, Gaz
  - Latéral et Vertical : propulseurs
  - Boost : touche ou bouton de boost
  - Pause : touche Pause/Attn par défaut

Si la manette des gaz a un zéro au centre (marche arrière),
cochez "Gaz avec zéro au centre" dans la section Secousses.


------------------------------------------------------------
6. FONCTIONS
------------------------------------------------------------

  PAUSE
    Touche Pause/Attn, ou bouton "Pause" en haut de la page.
    Coupe ou reprend tous les effets.

  PRÉRÉGLAGES
    Faible / Standard / Renforcé. Ils changent la force des
    mouvements et des secousses, sans toucher aux commandes.

  PROFILS
    Enregistre les réglages sous un nom. 
    Un profil ne change ni les commandes ni le mode d'utilisation.

  RÉGLAGES EN DIRECT
    Chaque curseur s'applique immédiatement, même en vol.


------------------------------------------------------------
7. BRUITAGES D'AMBIANCE (onglet "Bruitages")
------------------------------------------------------------

La page de réglages a deux onglets : "Caméra" (les mouvements
de tête) et "Bruitages". Les bruitages s'ajoutent aux sons du
jeu et suivent l'état du vaisseau :

  AMBIANCE COCKPIT    Les fichiers du dossier "sons\ambiance",
                      joués au hasard l'un après l'autre.
  ALERTES DE FOND     bips de console et carillons lointains ;
                      alerte étouffée en cas de danger, surchauffe,
                      carburant bas ou interdiction
  RADIO DU CONTRÔLE   extraits des enregistrements présents, 
		      en arrière plan sur la fréquence de la 
		      station, tout le temps à proximité d'une
                      station ou d'une installation (arrivée,
                      appontage, décollage, sortie) ; coupés
                      moteurs arrêtés sur le pad. Courtes
                      transmissions quand un autre vaisseau
                      t'envoie un message.
  AMBIANCE HANGAR     machinerie et annonces lointaines à quai

Chaque catégorie s'active ou se coupe séparément, avec son
volume et un bouton "Écouter" pour l'essayer.

Les bruitages utilisent le journal d'Elite : si la page
indique "Journal introuvable", ils ne savent pas quand jouer.


------------------------------------------------------------
8. EN CAS DE PROBLÈME
------------------------------------------------------------

  L'image saccade, deux vues alternent
    -> Deux head trackings pilotent la vue : Tobii Game Hub
       encore ouvert, logiciel TrackIR ouvert,
       ou OpenTrack réglé en sortie "freetrack".

  Message "OpenTrack introuvable"
    -> Installez OpenTrack. S'il est installé ailleurs, ouvrez
       config.json (à côté de l'exe) avec le Bloc-notes et
       indiquez son dossier :
       "opentrack_dir": "C:/Program Files (x86)/opentrack"

  "Jeu non connecté" sur la page
    -> Lancez Elite APRÈS le mod : le jeu cherche le TrackIR
       à son démarrage.

  Le tracker est marqué "—" (rien reçu)
    -> OpenTrack n'est pas lancé (Start), ou sa sortie n'est
       pas "UDP over network" vers 127.0.0.1, port 5555.
       Cliquez sur "?" pour revoir la mise en place.

  "Port indisponible"
    -> Un autre programme utilise déjà ce port. Changez-le dans
       "Mode d'utilisation", et mettez le même dans la sortie
       d'OpenTrack.

  La vue ne bouge pas quand je pilote
    -> Refaire "Détecter" pour les axes (section Axes HOTAS).

  "Journal introuvable"
    -> Les secousses du jeu et la détection de la
       supercroisière ne marchent pas. Dans config.json,
       indiquez le dossier du journal d'Elite :
       "journal_dir": "C:/Users/TON_NOM/Saved Games/Frontier Developments/Elite Dangerous"

  Un mouvement part du mauvais côté
    -> Section "Inverser un mouvement" sur la page.

  Aucun bruitage
    -> Onglet "Bruitages" : vérifiez que les bruitages sont
       activés et le volume. Le statut indique si l'audio est
       disponible. Les sons ne jouent qu'à bord du vaisseau.

  Mal des transports
    -> Choisis le préréglage "Faible".

  L'antivirus bloque l'exe
    -> Faux positif courant pour ce type de programme :
       ajoutez une exception pour le dossier du mod.
